Install **MPA-0.3-debug.apk** below on Android 8.0 or newer. This is an experimental test prerelease with a larger APK because its face and scene models are bundled for offline use.

### New features

- Full-screen image viewing, swipe browsing, pinch/double-tap zoom, and video import/playback/export.
- Photo editing: crop, rotate, straighten, exposure, contrast, saturation, warmth, filters, and drawing. Saved drafts, undo/redo, and separate edited copies preserve originals. JPEG output is bounded to 4096 pixels and may adapt lower on small-memory phones.
- Favorites, archive, albums, pinned offline albums, and search by filename, capture date, saved places, confirmed people, or optional object labels.
- Optional on-device face detection and MobileFaceNet matching suggestions, unknown groups, naming, corrections, merging, individual reassignment, and deletion of the local biometric index.
- A map of embedded or manually entered photo locations, clustered pins, and optional OpenStreetMap tiles. Online tiles are off by default.
- Recursive Drive discovery, transaction-safe change checkpoints, thumbnails loaded as needed, durable download queues, and handling of external file/folder changes. Changed remote content remains separate from preserved local snapshots.
- Storage controls: default 2 GiB disposable-download budget and 256 MiB thumbnail budget. Protected imports, edited copies, pins, pinned albums, drafts, pending handoffs, and active readers are kept. Eviction rechecks the current Drive revision/checksum before removing a download.
- AI handoff continues through official ChatGPT, Gemini, or Claude apps using the user's subscription, with no AI API keys.

### Install and Google setup

The v0.2 debug signing key was temporary and cannot be recovered from its APK. This build uses a different certificate. **Do not uninstall v0.2 while it contains the only copies of photos.** First verify those photos are backed up in Drive or that source copies still exist. Android requires the same signer to upgrade an installed app; if it refuses this APK, preserve your media before uninstalling.

Register an additional Android OAuth client in your existing Google Cloud project using package **`com.myphotosanywhere.mpa`** and the debug **SHA-1 in the attached MPA-0.3-signing-report.txt**. You can keep the old OAuth client as well. No API key, Android client secret, or AI credential needs to be entered in MPA. See the attached Google setup guide.

After installing, reconnect the Google account and select the same Drive folder. Its ordinary image/video files can be indexed and downloaded again. Local-only v0.2 handoffs and metadata are removed by an uninstall. The Room v1/v2→v3 upgrade is tested for installations signed with a matching key; an uninstall is not a database migration.

CI now caches its debug keystore for subsequent builds, but a cache loss can still change the certificate. Production signing will need an owner-managed key.

### Validation and limits

The attached BUILD_EVIDENCE.json records passing unit/integration and emulator tests, APK size, and checksum. The release reuses the APK from the referenced successful source build; it does not rebuild it during publication. An emulator smoke test covers gallery viewing/edit-copy preservation and offline Android face inference/detection. The attached feature guide lists phone checks for real Drive transfers, face accuracy, location browsing, and cache behavior.

Face matching is experimental and requires your review; it has not been calibrated on your photo collection. Face crops, names, embeddings, albums, edit recipes, and user place labels remain on the phone. Video editing, individual pet recognition, encrypted metadata recovery across devices, and remote trash/recovery remain future work. MPA is not yet a complete Google Photos replacement.
