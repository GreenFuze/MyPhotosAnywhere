# MyPhotosAnywhere 0.5.5 — Dismiss import errors

Version 0.5.5 / code 16 / Room v8. Update the existing installation; the established upgrade/OAuth signer and saved import progress are preserved.

- Stopped imports with saved errors now offer **Dismiss errors** in Storage. This clears the import's saved job/file/historical-download messages, including its preview, and dismisses its summary notification. Dismissal survives app restarts.
- Import history/status, selected files, the original destination, ZIP access, staged media, reserved Drive IDs, upload sessions, offsets and verified media are retained. A failed import stays failed and **Import selected / Resume** remains available. Dismissal does not retry, cancel or delete anything.
- Current messages for active imports/downloads remain visible; pause first to dismiss them. The database transaction rechecks that the job is stopped, protecting a job resumed since the button appeared. New failures appear normally after dismissal.
- Background progress and bounded Drive connection recovery from 0.5.4 remain included. This increment keeps the existing Drive-backed import storage contract.

To test: install this update, open **Storage** and choose **Dismiss errors** beside an old import. Reopen MPA and check that its messages stay cleared while its saved counts/status and Resume action remain. For an active import, pause it before dismissing its messages. Use Resume separately if you want to retry it. Keep original ZIPs needed by unfinished imports.
