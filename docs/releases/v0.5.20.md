# MPA 0.5.20 — Immersive viewer

Photos use a full-size viewer canvas with overlaid controls. Single-tap an image to hide/show the controls, or use the labeled 48dp button/accessibility action. Hiding controls keeps the same media bounds; it does not reload the image or change the opened sequence. The choice survives rotation. Swipe **up** or choose Info for Details; opening Details reveals controls. System Back returns to the anchored gallery.

Preview/original captions, authorization recovery and operation errors remain visible while controls are hidden. Existing double-tap zoom, pinch/pan, horizontal paging, original verification, cache leases and bounded decoding remain. Video playback retains its native tap behavior and has an explicit controls toggle. No automatic hide timer, filmstrip, new video streaming, storage/import rewrite or database migration is included.

The [photo-first refinement roadmap](https://github.com/GreenFuze/MyPhotosAnywhere/blob/main/docs/PHOTO_FIRST_REFINEMENT_ROADMAP.md) describes five subsequent increments: visual Collections, a richer mosaic, continuous selection, date navigation, and management/acceptance polish. Their scope remains subject to implementation findings and owner feedback.
