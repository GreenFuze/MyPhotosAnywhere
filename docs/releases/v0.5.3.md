# MyPhotosAnywhere 0.5.3 — Background import progress

Version 0.5.3 / code 14 / Room v8. Update the existing installation; the established upgrade/OAuth signer is preserved.

- Takeout and Photos Picker imports continue through Android WorkManager when MPA is in the background. Active imports now use a data-sync foreground service with the monochrome MPA status-bar icon and a silent progress notification.
- The notification shows verified files / selected files and the current file's preparation, upload percentage or metadata commit. Tap it to open Storage. Completion, pause, cancellation and failure leave a dismissible summary.
- Android 13+ notification permission is requested on import start/resume. Denying permission does not block imports. Storage has controls to enable notifications for an already running job and open Android notification settings.
- One worker processes files within an eight-minute batch before yielding at a checkpoint. Existing destination/network constraints, upload IDs, acknowledged offsets, metadata, source ZIP access and cleanup remain compatible. User-selected archives remain untouched.

To test: pause the current import before installing the update, open **Storage**, allow MPA notifications and choose **Import selected / Resume**. Leave MPA, check the icon/progress in the notification shade, then tap it to return to Storage. Compare verified counts, pause/resume, and check the completion summary. A disabled **Photo imports** channel also hides notifications.

Validated: 152 unit/integration tests, zero lint errors, CPU model checks, APK assembly and 20 native tests on each of Android 10/API 29 and Android 15/API 35 (40 total), with zero failures/errors/skips.
