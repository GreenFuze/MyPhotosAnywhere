# MyPhotosAnywhere 0.5.15

[Download MPA-0.5.15-debug.apk](https://github.com/GreenFuze/MyPhotosAnywhere/releases/download/v0.5.15/MPA-0.5.15-debug.apk).

Install over the existing MPA app. Package `com.myphotosanywhere.mpa`, established upgrade signer and Room schema 9 are preserved; no uninstall or app-data clearing is required.

## Changes

- **Saved photo size:** Photos > Filters > Photo size offers Large (2 columns), Default (3) and Compact (4). The preference also applies to chronological collection and Search result grids. It survives app restart and does not change recognition, network, cache or backup consent.
- **Pinch density:** spread two fingers for larger photos or pinch inward for a denser grid. Each gesture changes at most one step. Single-finger scrolling and long-press selection retain their paths; pinch density is disabled during selection. The visible canonical photo and measured pixel offset are restored when the layout changes and after rotation.
- **Date rail:** a compact month/year control in the gallery opens quick date navigation. Scrub the month slider or enter a year and choose a month, then tap Jump. The existing exact-day picker remains in Photos > Filters > Jump to date. Explicit controls provide alternatives to gestures.
- **Correct seeking:** bounds and jumps reuse the existing read-only projection, source/organization/search visibility and verified offline-original checks. Unknown dates remain browsable without invented timestamps. Date grouping uses the device timezone. Cancel preserves the viewport; invalid years disable Jump; stale requests cannot override a new context. Operational errors keep the grid visible with retry.
- Pixel restoration waits for the new page/density layout to be measured before correcting its offset, including when the target photo was already visible before the seek. The date regression checks the actual target identity, zero scroll offset within the grid's declared 2dp content inset, and unchanged canonical/pixel anchors after Cancel.
- **Subtle feedback:** navigation selection colors use Compose's normal system-scaled animation clock. Grid geometry and viewer rendering are not animated or rewritten. Imported people counts use singular/plural wording.
- **Keyboard continuity:** year entry has a Done action, and month selection/finished scrubbing clear the keyboard before Jump. Search Back uses current platform keyboard visibility so an ongoing hide animation cannot consume the return to the originating gallery. The existing imported-people/Search continuity assertion remains unchanged.
- **Query continuity:** cached results remain visible while a new filter loads, with a progress overlay that does not move the grid. Each media row carries its immutable query scope: stale results cannot open/select against another query, while cached photos from the current query remain usable during restoration.
