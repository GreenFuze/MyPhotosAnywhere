# MyPhotosAnywhere 0.5.1

MPA automatically uses the only connected Google Drive folder for new imports. Takeout ZIP imports now offer a URL download, automatic processing and verified phone cleanup.

- With one connected Drive folder, no extra default-selection step is needed. Ordinary backup can remain paused. Multiple folders still require a chosen default; existing imports keep their captured destination.
- In **Storage → Import Takeout ZIP parts**, choose local/USB files or **Download ZIP from URL**. Paste a direct HTTPS ZIP download link. **Download and import** downloads privately, validates the archive, pairs metadata and imports supported media automatically. An optional preview stops before upload.
- Downloads show progress, obey the destination's network preference, run with Android foreground work, and support pause/resume. Strong ETag and checked byte ranges protect resumed downloads; servers without safe resume support restart from zero. Signed links are encrypted with Android Keystore before persistence.
- MPA removes its downloaded ZIP and leftover completed transfer staging only after all media is verified and committed in Drive. Skipped/unsupported files keep the ZIP for review, with an explicit phone-delete action. User-selected ZIPs, browser Downloads files, Google Photos and Drive originals remain intact.
- Room v8 preserves existing media, reviewed names, import/upload checkpoints and Drive sync state. The established upgrade/OAuth signer, icon, recognition models and thresholds are unchanged.

## Phone retest

1. Install **MPA-0.5.1-debug.apk** over the existing app. Do not uninstall. Confirm **Storage → Google setup details** shows **MPA 0.5.1 (12)** and the library/names remain present.
2. With one Drive folder connected and ordinary backup paused, import a small Takeout ZIP. Confirm the displayed destination is automatic. With several folders, choose a default and confirm changing it does not retarget an existing job.
3. Choose **Download ZIP from URL**, paste a small direct ZIP link, and leave automatic import checked. Confirm progress, metadata, uploaded bytes and final phone ZIP cleanup. Repeat once to check duplicate handling.
4. Pause a download, restart MPA, and resume. Test a network interruption, expired link and HTML sign-in page. Paste a fresh link when needed. Skipped or unsupported media must retain the downloaded archive for review.
5. Uncheck automatic import to review selection first. Test **Delete downloaded ZIP from phone** after pausing; verified media must remain in Drive. Keep an unrelated local/USB ZIP and confirm it is untouched.

Google's emailed Takeout URL normally opens a browser-authenticated export page; it is not necessarily a direct ZIP link. MPA does not read browser cookies or automate password/2-step verification. Download in the browser and select the local ZIP when required. Existing Picker Cloud configuration remains valid with the preserved signer.

Limits: 50 GiB per downloaded ZIP, enough phone storage for the entire ZIP plus a 314 MiB reserve, 250 MiB per media file, 10,000 manifest entries, 128 KiB per JSON and 2 MiB / 10,000 assets per XMP catalogue. No second extracted library is created. Use smaller Takeout parts on phones. Real Google-account and S23 Ultra acceptance still needs the owner's test.
