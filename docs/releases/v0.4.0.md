# MyPhotosAnywhere 0.4.0

MPA connects several Google Drive folders/accounts in one gallery, with one default destination for new imports and edited copies and a shared phone-wide person identity library.

This release adds:

- Opt-in source-scoped XMP catalogue backup, a transactional offline outbox, conditional revision checks and recovery preview. Original photo bytes and embedded EXIF are preserved. Shared-folder readers can read names and locations in its catalogue.
- Stable normalized face regions that preserve reviewed names through unambiguous redetection. Recovered crops and embeddings are rebuilt locally.
- Bounded phone indexing across connected sources, verified original downloads, cache protection for pending scans, pause/resume, heat checks and a charging-only night window in phone-local time.
- The MPA adaptive/themed launcher icon, existing editing/library/map/video tools, and AI subscription handoffs through official provider apps. No AI API keys are required.

Download **MPA-0.4-debug.apk** below and install it on Android 8+. It retains the established 0.3/alpha signing certificate, so those installations can upgrade without clearing app data. Google OAuth must match the APK certificate; see the attached setup guide.

**This is a development APK for phone testing.** The human model is unchanged; suggestions require confirmation. Cat/dog labels are searchable, but individual pet recognition and Google Photos level accuracy are not included. Live Drive recovery, real-photo recognition, battery/heat and vendor background restrictions still need phone testing. XMP catalogues are currently limited to 2 MiB / 10,000 assets; adjacent/MWG sidecars, partitioning and automatic conflict merging are future work.

Read the attached **FEATURES_0_4.md** for opt-in behavior, recovery/conflict rules and the phone checklist. BUILD_EVIDENCE.json and SHA256SUMS.txt identify the exact tested APK.
