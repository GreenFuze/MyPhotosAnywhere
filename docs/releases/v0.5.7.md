# MyPhotosAnywhere 0.5.7 — Continuous imports and Drive ZIP reading

Version 0.5.7 / code 18 / Room v9. Install over the existing app; the established upgrade/OAuth signer, source grants and all saved import progress are preserved.

- Android 14+ imports use user-initiated transfer jobs for long background transfers, with an immediate system-associated notification, the job's assigned network, source network preferences and upload-size estimates. Older Android versions retain foreground WorkManager execution. Existing running imports migrate on visible reopen; background initialization never starts UIDT jobs.
- Connection retries remain inside active work, retaining the same progress notification and verified-file bar during bounded 30/60/120-second retries. Notification IDs survive process death and avoid hash collisions. **Pause import** in the notification preserves staged files, reserved remote IDs, sessions, offsets and committed media. Invalid data/permissions/storage failures still stop visibly; stopped work cannot be resurrected by a late network failure.
- **Import Takeout ZIP from Drive** browses connected source folders and reads checked byte ranges without storing the complete ZIP on the phone. Preview retains supplemental metadata; **Add Drive ZIP part** supports additional archives. Original source account/folder/revision and destination remain fixed; changed/moved archives fail safely. Source ZIPs are never deleted or modified.

Android 14+ allows users to swipe away ordinary ongoing transfer notifications; MPA cannot force an undismissible box. Android Stop/force-stop, network constraints, memory and thermal limits can interrupt jobs and remove active notifications. Eligible system-stopped jobs may resume automatically; reopen MPA if recovery is deferred. No uninterrupted Samsung/overnight behavior is claimed from synthetic checks.

Takeout's Add to Drive delivery creates ZIP archives. This new reader saves full-archive phone storage/download setup; it still stages and uploads individual photos into MPA's existing Drive layout (or reuses exact verified duplicates). Keeping originals permanently inside ZIPs to avoid re-upload requires a separate storage feature and is not included. Already-extracted Drive media still uses ordinary sync without uploading it again.

To test background behavior: update in place, reopen **Storage**, and resume the same paused/failed import. Allow notifications, leave MPA, lock the phone and watch verified counts. Check Pause from the notification, then Resume in Storage. Restore connectivity after a transient failure and confirm progress/checkpoints continue. An explicit Android Stop may require reopening. Do not create a replacement import just to upgrade.

To test Drive Takeout: choose Add to Drive in Takeout, connect the export's Drive folder as an existing collection, then select **Import Takeout ZIP from Drive**. Preview and import a small album first, adding ZIP parts as needed. The archive remains in Drive and consumes quota in addition to extracted destination media. Existing 250 MiB media and 10,000-entry/asset catalogue limits remain; range reads use a 256 KiB cache with 64 MiB preview and 512 MiB per-item traffic limits.
