# MyPhotosAnywhere 0.5.10

[Download MPA-0.5.10-debug.apk](https://github.com/GreenFuze/MyPhotosAnywhere/releases/download/v0.5.10/MPA-0.5.10-debug.apk).

Install this APK over the existing MPA app. It retains package `com.myphotosanywhere.mpa` and the established upgrade signing certificate; uninstalling or clearing app data is not required.

## Changes

- Photos, Collections and Search form the primary navigation. The compact app bar and floating navigation leave more room for photos; source management and import activity remain reachable.
- Photos and the existing filtered collection grids use one date-grouped, paged timeline across connected sources and local/remote availability. Jump to date seeks directly to older media.
- Viewer previews open immediately. A disposable sequence index keeps neighbor identities stable during imports; existing original verification, zoom/gesture, cache-lease and video lifecycle behavior is reused.
- Stable dependency/toolchain updates target Android API 37, with minimum API 26. Storage budgets, job-ID ranges, backup exclusions, launcher resources and drawing allocations were cleaned up.
- Room schema 9, existing media metadata/relationships, drafts, pins, sources, consent, durable jobs and captured import destinations are retained.

## Known limits and phone acceptance

- **Samsung S23 Ultra acceptance and the reported JPEG crash remain unverified.** Synthetic emulator checks do not establish the cause or resolution of that phone crash.
- At 100,000 items, initial viewer sequence preparation measured 26.5 seconds on API 29 and 7.8–8.3 seconds on API 35/37 CI emulators. The selected preview opens before preparation finishes; this is a recorded performance limitation. Concurrent import writes completed in 2.9–4.3 ms while preparation preserved the opened sequence.
- Android/SDK instrumentation, rendering, absent Google Play services on test images and model-delegate runtime messages are retained in CI logcat. No fatal exception, native fatal signal, ANR or out-of-memory error appears in those captured logs. Real-account OAuth, network and Samsung behavior still need device testing.
- Broader Details/gesture, selection, Collections, Search and management redesigns remain subsequent work. Takeout URL input remains absent.
