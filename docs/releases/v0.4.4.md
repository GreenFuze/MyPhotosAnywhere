# MyPhotosAnywhere 0.4.4

Large Drive folders could restart their entire discovery after MPA stopped. This update
saves folder/page progress, resumes bounded discovery passes and makes refresh state
visible near the top of Storage.

- Browse media progressively while discovery runs. Original downloads and recognition
  keep their existing opt-in, network, pause and scheduling rules.
- Per-source Refresh/Retry shows saved discovery pages, last successful sync, failures
  and reconnect needs above lengthy Storage settings.
- Incomplete listings and failed passes preserve existing media. Only a completed
  traversal can remove absent entries from the current gallery.
- Replaced remote bytes receive a fresh thumbnail while old local snapshots and reviewed
  faces remain attached to their original content.
- Room v5 upgrades to v6 while preserving photos, reviewed identities, upload sessions,
  destination selection and Drive change checkpoints.

This is a development release of the first Drive-ingestion increment. Takeout, Photos
Picker and the shared migration engine remain later work. The face model and similarity
thresholds are unchanged. Android background refresh is eventual.

## Phone retest

1. Install **MPA-0.4.4-debug.apk** over 0.4.3 without uninstalling. In Storage → Google
   setup details, confirm **MPA 0.4.4 (10)**. Existing photos, names and sign-in must survive.
2. With indexing disabled, add images/videos across nested Drive folders, then reopen MPA
   or choose **Refresh Drive**. Check progressive gallery results and saved page progress;
   discovery must not download all originals.
3. Close/force-stop during discovery, reopen and refresh. Progress should resume without
   duplicates; an interrupted traversal must preserve previously known items.
4. Rename, move, replace and trash a few test files. Refresh to convergence. Old downloaded
   snapshots and reviewed faces must remain recoverable after replacement/removal.
5. Interrupt connectivity during discovery. Check visible failure/waiting state, then
   reconnect and retry. Other sources should continue independently.
6. Retest overlapping folders, multiple accounts and each source's network preference.
   Enable indexing only when wanted and confirm pause/night/charging controls still apply.

See [the full bulk-ingestion checklist](https://github.com/GreenFuze/MyPhotosAnywhere/blob/v0.4.4/docs/FEATURES_0_4.md#bulk-drive-ingestion-in-044).
Use a test folder and retain independent copies when exercising remote changes.

Validated with **110 unit/integration tests, ten Android emulator tests, lint with zero
errors and CPU model checks**. The publisher verifies the established upgrade/OAuth
signer and reuses the passed CI APK. Local emulator installation
failed before app tests could run; live Google Drive and S23 Ultra acceptance remain the
purpose of this phone test release.
