# MyPhotosAnywhere 0.5.6 — Import recovery and duplicate indexing

Version 0.5.6 / code 17 / Room v9. Update the existing installation; the established upgrade/OAuth signer and saved import progress are preserved.

- Import no longer restarts its foreground service between eight-minute batches. Android foreground-start refusals leave **waiting for MPA**, preserving transfer checkpoints; reopening MPA queues recovery automatically. Legacy foreground waiting retries are replaced on reopen so their backoff cannot block recovery. **Pause** and **Cancel** stay authoritative, including late worker error/completion races.
- Exact duplicate lookup uses a local destination/SHA-256/size index populated from Drive metadata, covering nested media MPA has not downloaded. Every reused original still needs live remote SHA-256, MD5, size, version and selected-folder ancestry verification. Missing hashes, stale entries, moved/trashed files or another source/account cannot authorize reuse. Idle sources get a bounded metadata rescan after upgrading; active traversal checkpoints continue, with earlier pages gaining hashes on a later full scan.
- SHA-256, MD5 and ZIP CRC accumulate together during extraction. A combined integrity pass remains before upload or duplicate commit, preserving resumed-staging verification. Cancellation is checked each buffer; expensive state/free-space checks are throttled between start/end checks. The ZIP must still be read and individual media staged. No phone speed benchmark is claimed.
- Existing source grants, reserved Drive IDs, upload sessions/offsets, verified media, reviewed metadata, album memberships, original ZIPs and older releases remain preserved. Background progress, bounded Drive transport retries and **Dismiss errors** remain included.

To test: update MPA in place, reopen **Storage**, and resume the same unfinished import if it was paused or failed. Leave MPA with notifications enabled and watch verified counts advance. If Android refuses a new service start, tap/open MPA and confirm recovery without another Pause/Resume cycle. Android can still defer/stop work. Do not cancel and create a replacement import just to install this update.

Repeat a small completed Takeout import into the same destination after its Drive metadata scan completes. Exact verified media should be reused and album memberships retained. Check an externally uploaded nested copy as well. Edited/recompressed versions remain separate; this release does not implement visual deduplication or delete lower-quality originals. A shared Drive manifest, similar-image review and quality-preference policy are future stages.
