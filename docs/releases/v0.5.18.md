## Icon-led actions and organized Settings

Settings is now a grouped menu with icon-led rows: **Library**, **Backup and privacy**, and **Application**. Existing storage/cache, Recognition, Backup and metadata, Privacy and permissions, and About sections remain reachable through the same navigation history. Open it from **Accounts and sources > Settings**.

Sources shortcuts, selection and viewer actions use bundled vector icons with short visible labels. The Add menu has leading icons. Previous/next arrows flank the viewer position indicator. The viewer's Info icon opens Photo details; swipe up still opens the same sheet. Favorite uses an outline/filled shape as well as selected color and semantics.

Each action retains one complete accessible name and its disabled/selected state. Labels wrap at enlarged font sizes and action rows wrap instead of hiding required actions. Settings rows and labeled icon actions are at least 64dp tall; icon-only Info is 48dp. Source removal, file deletion and other destructive operations retain explicit wording and existing confirmation contracts.

Gallery anchors could drift or wait indefinitely when imports prepend rows or density changes remeasure the grid. Restoration now cancels obsolete placement and verifies the measured canonical photo and pixel offset. Reachable offsets remain exact; real scroll boundaries and crops larger than resized cells use the closest visible offset for the same photo.

Each attempt awaits an actual Android grid measurement. A five-second guard and eight-attempt invariant detect internal failures. Backgrounding cancels the wait; foregrounding restores the saved anchor. Ten deterministic unit cases and native import, rotation, background/resume, density and repeated-layout checks cover these paths.

Square and Mosaic retain separate grid/state lifetimes where their slot structure differs. Content callbacks capture one immutable geometry snapshot. Import/viewer tests finish restoration before fixture teardown; selection Back waits for the native dialog-to-Activity focus handoff. Existing action and data-preservation assertions remain.
The remainder changes presentation only. Timeline ordering, paging queries and budgets, the mosaic packing algorithm, imports, workers, original download verification, cache leases, recognition/map consent, stored metadata and viewer lifecycle/gestures remain. Room schema 9 is unchanged.
