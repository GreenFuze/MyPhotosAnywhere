MPA's first downloadable Android test prerelease. Install **MPA-0.2-debug.apk** from the assets below on a phone running Android 8.0 or newer.

### Try it on your phone

1. Sign in to GitHub with access to this private repository and download the APK below.
2. Open the downloaded APK and allow your browser or file manager to install apps when Android asks.
3. Import a few photos, browse the gallery, open photo details and GPS locations, and try an AI share-sheet handoff.
4. Before testing Drive sign-in, follow [Google Drive setup](https://github.com/GreenFuze/MyPhotosAnywhere/blob/main/docs/GOOGLE_DRIVE_SETUP.md). Register the Android package `com.myphotosanywhere.mpa` with the SHA-1 in **MPA-0.2-signing-report.txt**, enable the Drive API, and add your account as an OAuth test user if required. The setup guide is also attached below.

### Included

- Local photo import, persistent gallery, thumbnails, and EXIF GPS details.
- Google account authorization and selection or creation of a Drive library folder.
- Explicitly enabled background backup with resumable uploads and integrity checks; unmetered networks by default.
- Browsing and downloading images directly in the selected Drive folder.
- AI share-sheet handoff for ChatGPT, Gemini, or Claude using the user's installed provider app and subscription, plus importing a saved result as an edited copy. Provider editing support varies; there is no direct subscription API integration.

### Current limits

This is a debug-signed test build. Google Drive authorization and device behavior still need testing on a real phone. Full photo editing, face detection and recognition, automatic cloud indexing, cache eviction, and map browsing are planned.

If Android refuses an upgrade because an earlier APK has a different signing certificate, preserve any photos stored only inside MPA before uninstalling: uninstalling removes app data. CI debug signing keys can differ across builds.
