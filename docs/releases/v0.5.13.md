# MyPhotosAnywhere 0.5.13

[Download MPA-0.5.13-debug.apk](https://github.com/GreenFuze/MyPhotosAnywhere/releases/download/v0.5.13/MPA-0.5.13-debug.apk).

Install over the existing MPA app. Package `com.myphotosanywhere.mpa`, the established upgrade signer and Room schema 9 are preserved. Uninstalling or clearing app data is not required.

## Changes

- A dedicated Search bar with clear-query, Search IME action, visual discovery shortcuts and eight clearable recent queries. Recents belong to saved screen state; they are not written to a new persistent search database, preferences or analytics.
- Independent source, Photos/Videos, organization and local-calendar date-range filters. Editing or clearing Search filters does not change the Photos timeline. Date boundaries handle daylight saving and skipped calendar days.
- Globally chronological, paged Search results use the canonical media projection. Bounded cancellable cursor reads replace full-library Search subscriptions. No original is downloaded just to search metadata or display a result tile.
- Existing local filename, place, label, date, MIME, person and imported-metadata matching is preserved, including favorite/video/image/edit/GPS keywords. Album names are added. Unicode and punctuation retain literal matching; no unsupported relevance or Ask Photos behavior is claimed. Unlinked remote-only matching remains filename/MIME matching.
- Search results reuse accessible stable-ID selection, preview-first viewing and disposable viewer snapshots. Opening/swiping/rotating while imports add items preserves the selected sequence and return anchor. Back returns to the originating gallery/collection context; keyboard and sheet dismissal have explicit boundaries.
- Lifecycle-aware recognition status; no recognition, map access, new server or paid AI service is activated. Original decoding, downloads, import jobs/checkpoints, captured destinations and persisted media relationships remain intact. Details still opens on **swipe up**.

## Known limits and remaining acceptance

- **Samsung S23 Ultra acceptance and the previously reported JPEG crash remain unverified.** Emulator fixtures do not establish that crash's cause or resolution. Real-account OAuth/network and Samsung lifecycle behavior still need phone validation.
- At 100,000 indexed items, a sparse first Search page measured 0.59–1.03 seconds and a full no-match scan measured 5.13–7.27 seconds across CI emulators. These are measured fixtures, not phone guarantees. Search remains a linear indexed-metadata scan without a new full-text table; its cursor windows and retained pages are bounded, and matched text payloads are discarded before retention.
- Search text is bounded to 256 characters with an explicit limit message. Recent queries are bounded to eight and remain clearable. Remote-only metadata coverage differs from downloaded/indexed local records. Recognition may be disabled or incomplete; results reflect the metadata actually present.
- Existing selection limits/manual external-AI result import remain. Takeout URL input remains absent. Activity, source and settings reorganization remains subsequent work.
