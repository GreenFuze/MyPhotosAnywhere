# MPA 0.5.33 — device folders and space cleanup

Candidate; publication requires final automated checks and independent APK verification.

- Photos offers Android photo access directly. With permission, Camera and other device images/videos join the gallery automatically; unbacked device photos have no Drive badge.
- Collections > On this device groups readable photos by their actual directory and storage volume. Folder galleries use the existing paging, viewer and selection behavior.
- Back up is available for readable local photos without a verified Drive copy. Explicit backup sends the original and a separate, verified portable XMP file containing available dates, location, labels, people, albums and edit information. It does not enable automatic camera uploads. Private embeddings and face crops remain on this device.
- Original and annotation checkpoints are separate: retrying annotations reuses the verified original and reserved sidecar identity. Existing jobs retain their captured destination. Android may require separate permission for original location; previously retained originals remain unchanged.
- Sources > Free up space and Settings > Storage and cache show a size/count estimate and confirmation. Cleanup rechecks each Drive download before removal and keeps thumbnails and metadata. Camera files, local-only originals, offline pins, drafts, active readers and pending work are protected. Recoverable failures retain that file and allow other downloads to be processed.

Room 11-to-12 is additive: directory references and explicit metadata receipts only. Historical schema files, photo identities, originals and existing import/transfer checkpoints are preserved.

Physical Samsung S23 Ultra acceptance, live Google authorization/Drive transfers and human TalkBack remain unverified until exercised. The earlier JPEG crash remains unreproduced. Processor architecture and object-search changes are deferred.
