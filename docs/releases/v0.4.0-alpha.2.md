### Multi-source behavior

- Connect several folders in one Google account or folders in different accounts. Use **Storage → Add Drive folder** or **Add another Google account**; **Manage source** selects its settings.
- Browse one combined gallery or filter by source. Sync, change tokens, thumbnails, downloads and network preferences use each file's account/folder, independently of the source open in Storage.
- Choose **Use as default backup destination** for one writable folder. Newly imported photos and edited copies use that destination. Other sources are not upload targets. Previously assigned assets retain their original destination and are not copied automatically when the default changes.
- Remove one source without stopping other sources or deleting local photos and people corrections.
- Human matching suggestions share the phone-wide identity library across accounts. Overlapping folders in the same account reuse a verified local photo and its reviewed identity when file ID, checksum and size match. Separate-account copies are not automatically merged.
- The database upgrade preserves the previous connection, media, reviewed names, upload sessions and change tokens.

### Install and Google setup

The attached signing report identifies the exact certificate for this APK. Google OAuth uses package **com.myphotosanywhere.mpa** and that SHA-1. When it matches your installed 0.3 or 0.4 alpha 1 APK, Android can upgrade it and retain app data; the Room v3→v4 upgrade is tested. Preserve source photos and verify backups before any uninstall: uninstalling removes the private local library. No AI API key or Android client secret is entered in MPA.

CI caches the debug signer, so compare the attached certificate if Android refuses an upgrade. This remains a test build, not a production signing setup.

### Test on the phone

1. Upgrade from 0.3 or alpha 1 and confirm existing photos, people names and the default backup folder survive.
2. Add a second folder in the same account, then a folder in a second account. Each account must already be allowed by your Google OAuth testing configuration.
3. Refresh Drive. Check combined/source-filtered browsing, download a file from each source, then change the source open in Storage while a download is pending. Transfers must stay in their original source.
4. Choose one default destination. Import a new photo and save an edited copy; verify both appear only in that folder. Existing assigned uploads should not move when you switch the default.
5. Enable local face indexing for downloaded photos from both accounts. Name a person in one source and check suggestions in the other, reviewing all matches. Recognition accuracy still needs representative-photo evaluation.
6. Remove one source, then refresh/download from another. Local media and reviewed names should survive, and the remaining source should keep working.
7. Try overlapping parent/child folders and offline browsing. Protected imported files, edits and pins must survive disposable-cache clearing.
