# MyPhotosAnywhere 0.4.3

Detected faces could remain separate without explaining whether recognition data was missing or the similarity gate failed. Normal Scan now also reused successful unchanged scans. This update makes those results reviewable and adds a full face rescan.

- Unnamed groups use compatible valid embeddings, deterministic ordering and the existing complete-link similarity gate. Separate faces detected in the same photo stay separate automatically.
- Review each crop and select which appearances to name together. Possible matches appear under the named person's card as **Review N possible matches**; confirm the selected crops to add them to that person's photos.
- **Why separate?** shows missing/invalid recognition data, incompatible models, manual corrections, weak matches or ambiguity. Compare the closest named-person score and the closest compatible face in another photo. These are local cosine similarities, not identity probabilities.
- **Rescan all faces** repeats detection across the library, including previously successful scans. It preserves names, reviewed assignments and corrections. Connected originals may be downloaded again using the existing network preferences. Scan now retains its incremental behavior.

Download **MPA-0.4.3-debug.apk** and install over 0.4.2 without uninstalling. The established signer, Google OAuth certificate and Room v5 schema are unchanged. The bundled model, alignment preprocessing and experimental similarity thresholds are unchanged; this is a grouping/review and diagnostics update, not a measured recognition-accuracy improvement. Individual pet recognition remains future work.

Validated with **95 unit/integration tests, nine Android emulator tests and lint with zero errors**. The established signer and Room v5 schema are preserved.

## Three-photo phone retest

1. In Storage → Google setup details, confirm **MPA 0.4.3 (9)**. Existing Google authorization should remain available.
2. In People, enable face indexing if necessary, choose **Rescan all faces**, confirm and wait for scanning to finish. Existing names must survive.
3. Check unnamed groups, or **Review N possible matches** under the people already named. Inspect crops and confirm only the correct appearances. Each person's photo count should then include the confirmed photos.
4. For an appearance that stays separate, open **Why separate?** and report the status, closest named-person similarity and closest-face similarity, if shown. Check whether the displayed closest crop is the same person. No photo uploads are needed to report these values.

Two usable appearances can match without training on a large collection. Additional examples can help cover different poses and lighting. The current extractor may reject small, angled or poorly aligned detections; older records do not preserve the exact extraction rejection reason. Diagnostics distinguish missing vectors from weak/ambiguous scores, but do not yet identify the specific alignment gate that rejected a face.
