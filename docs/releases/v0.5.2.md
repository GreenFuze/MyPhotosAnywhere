# MyPhotosAnywhere 0.5.2 — Takeout ZIP file access fix

Version 0.5.2 / code 13 / Room v8. Update the existing installation; the established upgrade/OAuth signer is preserved.

- **Import Takeout ZIP parts** opens Android's Files picker directly. The URL input and fresh-link form are removed.
- ZIPs are read through Android's granted file descriptor, avoiding access-denied failures when reopening provider files by pathname. The app requests and retains lasting read access; providers that refuse it receive clear local-file recovery guidance.
- The sole connected Drive folder remains the automatic import destination. Existing media, metadata, import jobs, upload offsets and historical downloaded-archive cleanup remain compatible. User-selected ZIPs are preserved.

To test: open **Storage → Import Takeout ZIP parts**, select a downloaded ZIP in **Downloads**, check the preview/destination, then choose **Import selected / Resume**. Keep the ZIP until all files are verified in Drive. Android grants access through the picker; no separate broad storage permission is needed.

Validated: 144 unit/integration tests, zero lint errors, CPU model checks and 18 native tests on each of Android 10/API 29 and Android 15/API 35 (36 total), with zero failures/errors/skips. [Build](https://github.com/GreenFuze/MyPhotosAnywhere/actions/runs/38136233885) · [Android 10 and 15 checks](https://github.com/GreenFuze/MyPhotosAnywhere/actions/runs/38136233947). Provider tests cover a ZIP held in another app's private storage, persisted access and reader reconstruction, non-seekable data, denied access and refused persistence. The exact passed CI APK is published with the existing signer. Local Windows checks also passed all 144 tests, lint and both APK builds.

Limits remain: 250 MiB per media file, 10,000 manifest entries, 128 KiB supplemental JSON, 2 MiB/10,000-asset XMP catalogue, seekable archives. Google Photos Picker and opt-in verified Drive JSON conversion remain included. Real Google-account and S23 Ultra acceptance remains outstanding; emulator tests do not prove the owner's exact export/provider combination.
