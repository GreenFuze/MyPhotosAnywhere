# MPA 0.5.19 — Takeout metadata preview

Takeout import previews now show how many media items have matched metadata, exported people labels, missing sidecars or unreadable metadata. Filters let you inspect **People labels**, **Without metadata**, and **Needs review**, then return to **All items**. Filters never change your import selection; selected-media and selected-people totals remain accurate. Open Activity or Import history, expand the job, and choose **Preview selection and metadata**.

Exported names become photo labels under **Collections > People > Imported people** after the corresponding photos are imported. They remain separate from confirmed face identities. The preview does not start recognition or transfer Google's face models or coordinates. Malformed provider records remain explicit and preserved; cancellation propagates and stale/duplicate internal identities fail fast. Parsing runs off the UI thread and transfer-progress/selection updates reuse parsed metadata.

## Owner export inspection

A read-only local check of the provided extracted Takeout part using MPA's existing decoder found **1,661 media files in recognized formats**, **1,644 sidecars**, and **934 sidecars containing people names**. Every sidecar parsed and uniquely matched; **17 media files had no sidecar**. **1,647 media files meet the existing import size limit**; 14 MP4s exceed 250 MiB and remain unsupported, with their source files preserved. People labels occur on 923 size-eligible media items and 11 oversized videos. The preview distinguishes all discovered labels from selected importable media. No private photos, paths, names or raw records were copied into public fixtures or artifacts. This establishes the exported format and matching behavior; it does not establish what an earlier phone import retained. The decoder and size limit required no change for this part.
