# Public repository and upgrade signing

The owner authorized making GreenFuze/MyPhotosAnywhere public and migrating the established upgrade key from an Actions cache into an encrypted repository secret.

Before conversion, a redacted gitleaks 8.30.1 scan covered all 104 nonempty historical commits and reported no leaks. Actions was paused during conversion. External fork PRs require approval from the owner for every external contributor.

Owner-only recovery run 38252373602 restored the existing cache and exported only AES-256-GCM ciphertext with an RSA-4096 OAEP-SHA256 wrapped key. Independent run 38252511101 verified that the installed repository secret preserves certificate SHA-256 `1262430ed1e257b54a4c09697cbc63bc148af11755485bcf7b2c66492f0379b4`. The obsolete signing cache and temporary recovery branch were removed after successful verification. A local recovery copy is restricted to the owner's Windows account and remains outside the repository.

Trusted push builds verify and materialize the signing secret only inside the disposable runner's temporary directory. The key is excluded from cache and artifact paths and removed after building. Fork PRs receive no upgrade secret and use a separate test signer. Internal PRs reuse their branch's push validation; separate event concurrency prevents a skipped PR run from cancelling a signed push build.

The final APK still requires independent package/version/signature/checksum verification before publication. Standard public GitHub-hosted runners now start successfully; no paid runner was enabled.
