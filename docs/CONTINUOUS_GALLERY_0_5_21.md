# MPA 0.5.21 — continuous photo grid

Owner refinement supersedes the original permanent-date-header recommendation. Photos and shared timeline grids render contiguous thumbnails without full-width date rows, in Mosaic and Square. Rows may contain photos from different calendar days, months and years. The floating month/year capsule remains, including its accessible full-date context and Jump to date action. Photo descriptions and Details preserve dates; missing dates remain honest. Device timezone changes update capsule/thumbnail descriptions and retain the media anchor.

The change removes separator insertion from the existing paged presentation and supplies media-only items to the existing layout planner. Ordering, timestamp provenance, filters, paging budget, queries, viewer sessions, storage, metadata and imports are unchanged. Schema 9 and the established upgrade signer remain. Version 0.5.21/code 32 is a focused owner-requested increment ahead of visual Collections, now planned for 0.5.22. Full strict host/native API29/35/37 gates, cross-date geometry/continuity checks and exact signed CI APK verification precede publication. S23 Ultra acceptance remains pending.

When different dates share the first visible row, the capsule follows the retained canonical anchor in that row, using the same policy as scroll restoration. After scrolling beyond that row it advances to the next visible photo. Date seeking therefore retains its target date; an unknown-date anchor never borrows a neighbor's known timestamp.
