# MPA 0.5.16 — floating gallery date

The owner supplied a Google Photos screenshot showing a centered date pill above the scrolling grid. MPA now centers its existing date action over the photo viewport, removes the calendar icon and uses a rounded pill. The visible month/year comes from the first intersecting current-query photo. Its full device-local date is available to accessibility services without noisy live announcements. Unknown dates remain unknown; no location is invented.

Tapping the pill retains quick month/year navigation. Existing inline date headings, exact-day controls, selection behavior, paging, density, pixel anchors, imports and viewer contracts remain. This is a focused refinement to the completed UX batches, not another backend or viewer rewrite.

Version 0.5.16 / code 27 retains Room schema 9 and the established upgrade signer. Publication requires the final host/native matrix, strict diagnostic review and independent exact-CI-APK verification. S23 Ultra acceptance and the reported JPEG crash remain pending.
